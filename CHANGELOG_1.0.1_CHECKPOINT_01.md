# 1.0.1 development checkpoint 01

Stainless steel now inherits the former chrome steel durability values, and chrome steel inherits the former stainless steel durability values. This covers matched native equipment, shield reinforcement and conditional Armory/Combat Overhaul durability entries. Damage and mining values are unchanged. Reference material table and handbook updated. Existing server settings are preserved; no migration of existing item remaining durability is attempted.

Toolsmith: 27 candidate exact-key multipart shape overrides derived from Toolsmith 1.2.20's Meteoric Steel integration, with referenced shapes verified. These are design-only, NOT installed patches: load order, config condition timing, bindings, transforms and heat-treatment preservation still need investigation. Meteoric Steel overlap resolution remains pending. No production temperature, recipe, armor protection or quench changes in this checkpoint.

Development source only, not a release. Native compilation and in-game testing not performed.
