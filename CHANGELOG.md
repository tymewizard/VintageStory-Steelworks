# Changelog

## 1.0.0 — Initial public release

Consolidates 0.9.8 RC1 and its tested asset hotfixes.

### Added
- Tiered multiblock alloy furnace, coke fuel, passive and forced draft, eight internal molds and temperature-preserving ingot retrieval.
- Expanded alloy progression, specialty equipment and native heat treatment with reduced shatter increments.
- Server balance configuration and client rendering/tooltip options.
- Furnace heating, processing, fuel and cooling estimates, progress bars and specific pause diagnostics.
- Conditional Combat Overhaul Fork, Armory Fork, Crossbows Fork and Recycling Tools asset support.

### Fixed
- Missing ingot/plate atlas registrations for cast iron, nickel steel and chrome steel.
- Missing advanced metal nails and strips, including both smithing patterns and heavy shield crafting ingredients.
- 70 unique codes for added Armory smithing recipes; Recycling Tools shape texture fallback.
- Armor protection and shield reinforcement progression, outdated handbook heat-treatment text and invalid client settings fallback.

### Release notes
- Public mod metadata and build output names updated to 1.0.0. The installable package preserves the successfully compiled RC1 DLL and tested hotfix assets.
- Requires Vintage Story 1.22.7 and Expanded Matter 3.8.3. Optional integrations remain optional.
- Dedicated server and exhaustive optional compatibility tests remain pending. See README for scope and limitations.
